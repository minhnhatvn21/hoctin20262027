Hướng Dẫn Thêm Ảnh Chạy Offline

Giúp trang web hiển thị đúng ảnh thật của 6 thành viên khi chạy không cần internet.

  1. Tạo một thư mục mới đặt tên là images nằm chung thư mục với file HTML này.
  2. Lưu các file ảnh của 6 thành viên vào thư mục images/ với tên chính xác như sau:
    • tu_trinh.jpg (Nguyễn Thị Tú Trinh)
    • thuy_tien_ngo.jpg (Ngô Thị Thủy Tiên)
    • thuy_tien_tran.jpg (Trần Thủy Tiên)
    • anh_thu.jpg (Trần Anh Thư)
    • quynh_tram.jpg (Lê Quỳnh Trâm)
    • bao_tran.jpg (Đỗ Nguyễn Bảo Trân)
  3. Các ảnh kỷ niệm bổ sung trong thư mục: gallery_1.jpg, gallery_2.jpg, gallery_3.jpg.
  4. Lưu ý: Nếu chưa có file ảnh, trang web sẽ tự động hiển thị khung tên thay thế đẹp mắt nhờ tính năng dự phòng thông minh (fallback).
Bạn có thể sử dụng định dạng ảnh .jpg, .png hoặc .webp đều hoạt động hoàn hảo khi chạy offline!
