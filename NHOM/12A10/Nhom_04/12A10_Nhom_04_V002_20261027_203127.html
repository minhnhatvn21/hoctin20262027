3. Hạ Tầng Trang Web: Server ➔ Hosting ➔ Tên Miền

Nhiệm vụ phân công do thành viên Trần Như Ngọc trình bày

Bước 1

Server (Máy Chủ Web)

Máy tính có cấu hình phần cứng đặc biệt, chạy liên tục 24/7 với địa chỉ IP tĩnh để tiếp nhận yêu cầu HTTP/HTTPS từ người dùng trên toàn cầu.

Bước 2

Web Hosting

Dịch vụ chia nhỏ tài nguyên dung lượng lưu trữ trên Server. Nơi chứa file code index.html, CSS, JavaScript và tệp hình ảnh.

Bước 3

Tên Miền (Domain)

Tên gọi thay thế địa chỉ IP khô khan thành chuỗi dễ nhớ (Ví dụ: bai7-html.com) thông qua hệ thống phân giải DNS.

Quy trình truy cập một trang web:
Trình duyệt gõ Domain
Máy chủ DNS tra cứu IP
Hosting trả về index.html
